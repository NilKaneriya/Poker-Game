# Retest of the new build (2026-11-23)

Second browser test round, on the WebGL client deployed at 17:34 (Dubai time) against the
hosted server. Desktop Chrome, up to 7 accounts.

## Result

- Of the 11 issues from the first round: 6 fixed, 1 mostly fixed, 3 still open, 1 not retested.
- First full 6-player table: 6-way all-in paid out correctly (pot 5,370, chips total exactly
  6,000); a 7th player was refused with "Table is full".
- 47 more showdowns (186 hands) re-scored independently: 0 hand-ranking errors.
- Security re-audit: every attack sent straight to the server was rejected or neutralised.
- A 2:22 video of a full 3-player hand was made ([media/poker_3player_hand_demo.mp4](../../media/poker_3player_hand_demo.mp4)).
  It is put together from screenshots taken at each action, not recorded live.

## Open items and what happened to them

| Report item | Status after this round |
|---|---|
| Bug 5: input focus lag in WebGL (text into the previous field; a click right after typing ignored) | Still open; in README Known issues |
| Bug 6: "Your turn" countdown hidden while Hand history is open | Fixed in code (BUG-14): History closes when your turn starts |
| Bug 9: "server restarted" shown after the 2-minute grace period; text cut off | Fixed in code (BUG-14): separate "seat released" message, toast grows to fit |
| Bug 10: old result pop-up on a new table | Not retested (fixed in BUG-13) |
| Bug 11: a dealt card can briefly cover a name plate | Known, cosmetic; in README |
| New: countdown covers the top seat's cards | Fixed in code (BUG-14): countdown moved right of the top seat |
| New: 1 seat requested gives a 6-seat table | Fixed (BUG-14): clamped to 2 |
| New: redeploy reset accounts and stats on the hosted server | In README Known issues (set `MONGODB_URI` on the host) |
| New: "Remember me" signs a new tab into the last account | By design; the single-session rule signs the old tab out. README section 2 says to untick it |
| New: client no longer logs network traffic | Intended for the release build |

"Fixed in code" items need a new WebGL build (**Tools > Poker > Build Scenes**, then
**Poker > Build WebGL**) and a server redeploy before they can be retested.

## Not tested in this round

- A real restart of the hosted server (the restart did not reach the live server).
- Mobile layout (the WebGL page is a fixed 960x600 canvas).
- The break reminder firing (it appears after 60 minutes).
- Four of a kind, straight flush and royal flush were never dealt; they are covered by unit tests.
